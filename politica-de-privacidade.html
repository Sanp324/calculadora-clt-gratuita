Política de Privacidade

Última atualização: 10 de outubro de 2026

1. Quem opera este site

Este documento descreve a versão atual do site Direito CLT. O projeto é identificado publicamente como "Calculadora CLT Gratuita", sem que este nome constitua razão social ou indicação de pessoa jurídica. O contato para solicitações de privacidade pode ser feito pelo e-mail contato_calculadora.clt@yahoo.com. Nesta versão não são divulgados nome civil, CNPJ, endereço físico ou endereço comercial do responsável; o e-mail indicado é o canal de contato disponibilizado e não substitui, por si só, eventuais requisitos legais de identificação do controlador aplicáveis à operação do site. Não envie dados pessoais ou documentos por meio dos simuladores.

2. Dados inseridos nos simuladores

Os dados preenchidos nos formulários de rescisão, férias, seguro-desemprego e salário líquido são processados por JavaScript no navegador para mostrar estimativas. A versão atual não envia esses campos a um servidor nem os armazena intencionalmente. O histórico, cache, extensões ou recursos do próprio navegador podem, contudo, ter comportamentos próprios.

3. Acesso ao site e serviços externos

Os estilos visuais do site são gerados localmente com a biblioteca Tailwind CSS e servidos a partir de arquivos do próprio site (css/output.css), sem carregamento ativo do Tailwind por CDN externo. O site está previsto para ser hospedado no GitHub Pages, um serviço de hospedagem de sites estáticos. Segundo a documentação oficial do GitHub Pages, quando um site hospedado nesse serviço é visitado, o endereço IP do visitante é registrado e armazenado para fins de segurança, independentemente de o visitante estar ou não conectado ao GitHub. O código deste site não define cookies nem armazena dados no navegador. O GitHub informa utilizar cookies para proteger e analisar o uso de seus websites e oferece um mecanismo de preferências de cookies; como a lista e o comportamento dos cookies do provedor podem mudar e sua aplicação a um site estático específico não foi verificada individualmente, esta política não descreve cookies específicos definidos pelo GitHub nesta página. Para detalhes, consulte a página "GitHub Cookies" e a Política de Privacidade do GitHub.

Espaços de anúncio estão reservados no layout, mas nenhum serviço de publicidade ou análise de terceiros está ativo nesta versão — o Google AdSense não está integrado no momento. Pretende-se integrar publicidade (como o Google AdSense) no futuro; quando isso ocorrer, esta política deverá ser revisada antes da ativação para identificar os fornecedores, finalidades, tecnologias de rastreamento (inclusive cookies), compartilhamentos, prazos de retenção e opções de consentimento aplicáveis.

4. Direitos do titular

A Lei Geral de Proteção de Dados (Lei nº 13.709/2018) prevê direitos relacionados ao tratamento de dados pessoais. Para exercê-los ou tirar dúvidas, utilize o canal de contato indicado na seção 1 desta política (contato_calculadora.clt@yahoo.com). Dados de acesso tratados pela hospedagem podem exigir solicitação diretamente ao respectivo fornecedor.

5. Segurança e alterações

Adotamos a orientação de não inserir dados pessoais identificáveis nos simuladores. Nenhum serviço na internet pode garantir segurança absoluta. Esta política pode ser atualizada se o site, sua hospedagem ou as tecnologias utilizadas mudarem; a data no início da página indica a revisão mais recente.

6. Aviso sobre os simuladores

Os valores são estimativas informativas, calculadas localmente a partir dos dados digitados. Não são aconselhamento jurídico, contábil ou trabalhista e não substituem a conferência do RH, contador, advogado ou dos canais oficiais.
